Custom models for Island Sim

Put an FBX here named after a building and the game draws it instead of the built-in model:
  harbor, harbor_capital, house, house_3x2, house_4x3, fishery, drying, grove, toddy,
  lumber, quarry, coir, cowrie, mosque, palace

Size: 1 Blender metre = 1 tile. A 3x2 compound is 3 m by 2 m; most workshops are about 1 m by 1 m.
Origin: the centre of the plot, at ground level (Blender: Object > Set Origin, then put it at 0,0,0).
Export from Blender: File > Export > FBX, "Apply Transform" on, Path Mode "Copy" with the texture button on.
Press Play again after replacing a file. Delete the file to go back to the built-in model.
