# Reference images

Drop images here using the slot names below (any of `.jpg`, `.png`, `.webp`). Agents read this folder before designing, modelling or texturing. One image per slot is enough; add `-2`, `-3` for more.

| Slot | What to show |
|---|---|
| `world-atoll` | An aerial atoll: lagoon, reef ring, pass |
| `world-islands` | The three islands' character: palm beach, basalt mountain, flat cane fields |
| `mood-day` | The default afternoon look |
| `mood-dusk` | Dusk colour and light |
| `mood-night` | Night with lamps |
| `water` | Lagoon water, reef shallows, foam |
| `asset-palm` | Palms |
| `asset-pier` | Wooden piers |
| `asset-boat` | Cargo sloop or similar |
| `asset-fishing-hut` | Stilt fishing hut |
| `asset-house` | Island houses, thatch and terracotta |
| `ui` | HUD style you like (Anno 1800, Tropico 6) |

Use images you have the right to use, or note the source URL in `SOURCES.md` here.
